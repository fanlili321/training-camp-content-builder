# 训练营内容生成 Skill

用于根据用户素材、历史 PPT/课程、文字稿和上一期训练营成品，完成微信群图文训练营从策划到复盘的完整内容流程。

## 适用场景

- 根据素材策划新的训练营内容
- 先交付训练营大纲，再生成图文初稿
- 参考上一期成品统一群发格式和文风
- 从历史 PPT 中匹配配图并核对数据
- 标注语言问题、风险提示和修改建议
- 对照 AI 初稿与人工定稿，沉淀可复用规则

## 标准流程

1. 确认训练营名称、主题、受众和交付要求。
2. 读取本期素材、历史 PPT/课程、文字稿及上一期成品。
3. 输出训练营大纲，列明每天的主题、主要内容和参考素材。
4. 等待用户明确确认大纲。
5. 按确认后的大纲生成可直接用于微信群的图文初稿。
6. 等待文字确认后，再处理配图和数据更新。
7. 检查语言、事实、格式与合规风险；未经授权不直接修改人工定稿。
8. 对照 AI 初稿、人工修改稿和老板确认稿，总结可复用规则。

大纲是第一项正式交付物。大纲未确认时，不进入完整正文生成；文字未确认时，不批量制作或替换图片。

## 主要交付物

- 训练营内容大纲
- 训练营图文初稿
- 配图与风险提示清单
- 最终定稿复核结果
- 初稿与定稿差异及规则总结

## 使用方式

将本仓库目录放入 Codex 的 Skills 目录，例如：

```text
~/.codex/skills/training-camp-content-builder
```

当用户提出策划、起草、更新、审阅或复盘训练营内容时，Codex 会根据 Skill 描述自动匹配并执行对应阶段。

## 核心原则

- 上一期同类型训练营用于参考格式，本期素材用于确认事实。
- 训练营正式名称与当期主题必须区分。
- 数据缺失时标记待补，不猜测、不编造。
- 风险提示靠近相应内容，避免只放统一声明。
- 人工修改稿和老板确认稿默认只读，修改前需获得明确授权。
- 飞书写入后必须重新读取验证。

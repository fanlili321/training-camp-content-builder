# 训练营交付检查表

## 大纲

- [ ] 大纲是否作为独立交付物？
- [ ] 是否包含项目背景、内容说明、三列表格、待确认事项和产出节奏？
- [ ] 每一天是否标明重点介绍、简单提及和参考素材？
- [ ] 内容量是否符合单日字数？
- [ ] 是否明确列出删除项和内容禁区？
- [ ] 是否取得大纲明确确认后才生成正文？

## 正文结构

- [ ] 训练营名称与本期主题是否分开？本期主题是具体产品时，是否只写了训练营名称？
- [ ] 每天开场是否列出“主要包括以下N个内容”，顺序与正文一致？
- [ ] 当天总结是否引出次日主题？产品介绍日之前的预告是否没有点产品名？
- [ ] 是否对齐上一期同类型训练营格式？
- [ ] 每天是否包含开场、回顾/说明、当天主题、总结、答疑、咨询承接和预告/结营？
- [ ] 是否按群消息意群组织，并使用统一分隔符？
- [ ] 是否擅自增加互动题或作业？
- [ ] 产品那一天是否以上一期成品为底稿更新，而不是另写？

## 语言

- [ ] 是否存在错别字、重复词、病句和主谓不清？
- [ ] 口语表达是否自然而非营销化？
- [ ] 术语在全文是否统一？
- [ ] 当日总结和次日预告是否对应正文？
- [ ] 是否压缩过头，概念是否都有“也就是/简单来说”的解释句？

## 数据与事实

- [ ] 每个数字是否有对象、时间、指标和口径？
- [ ] 是否存在空缺数据句或占位符？
- [ ] 正文、图片、图注是否一致？（逐张核对图和配文的数字、日期，例：正文“2025年突破13000只”与图“截至2026年4月，14029只”不一致）
- [ ] 同一个指标全文是否只用一个日期口径？不同天出现同一指标、不同截止日期的数字时，统一或删掉其中一处。
- [ ] 时点数据是否标明截止日期？
- [ ] 是否把一次历史区间结果写成普遍结论？
- [ ] 是否写入了只有口述、没有核实的数据？
- [ ] 数据截止日期是否与本期素材（直播）对齐？长期使用的内容是否没有无谓追新？

## 图片

- [ ] 每张图是否单独成一条消息，前后都有 `★ ★ ★ ★ ★`，说明文字在图前？（用脚本扫全文，不靠肉眼）
- [ ] 换主推产品后，图里的文字是否还适用于新产品（如“基金经理离职”不适合指数增强组合）？
- [ ] 图里新增的指标，正文里的列表是否同步补上？
- [ ] 每张图是否有对应正文承接？
- [ ] 图片数据是否需要更新？
- [ ] 是否含具体产品名称、代码、机构、水印或无关二维码？
- [ ] 图片在手机端是否清晰？
- [ ] **逐张放大检查图中所有文字**：标题、图例、坐标轴、数据标签、图注、气泡框。有无重影、叠字、残留旧字、错别字、日期笔误、被裁切的文字？图例和标题是否与正文说法一致（如“某公募指数增强策略”与“指数增强投顾组合”不得混用或叠在一起）？
- [ ] 改过的图（去水印、改字、换图例）是否在原图上干净覆盖，而不是把新字直接压在旧字上？

## 合规

- [ ] 历史表现是否就近提示不代表未来？
- [ ] 是否存在“一定跑赢”“收益更好”等绝对表达？
- [ ] 股息是否被误写为固定收益？
- [ ] 私募增强是否被写成必然获得超额收益？
- [ ] 演示利率是否被误写为承诺收益？
- [ ] 是否提示早期退保风险？
- [ ] 港险是否限定为已有香港或海外资金的人群？
- [ ] 产品案例是否完成匿名化？
- [ ] 以渠道名义开营时，正文是否没有以IP为主语、没有星级说法，图片是否去掉了IP标识？

## 飞书

- [ ] 写入前是否读取最新版本？
- [ ] 是否保护用户内容、评论和图片？
- [ ] 是否只修改用户授权的范围？
- [ ] 写后是否重新读取验证？
- [ ] 整段替换前，是否列出了范围内的所有图片并逐张决定去留？
- [ ] 替换带评论的块后，是否没有代评论人关闭评论？

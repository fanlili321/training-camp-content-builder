# 训练营交付检查表

## 大纲

- [ ] 大纲是否作为独立交付物？
- [ ] 是否包含项目背景、内容说明、三列表格、待确认事项和产出节奏？
- [ ] 每一天是否标明重点介绍、简单提及和参考素材？
- [ ] 内容量是否符合单日字数？
- [ ] 是否明确列出删除项和内容禁区？
- [ ] 是否取得大纲明确确认后才生成正文？

## 正文结构

- [ ] 训练营名称与本期主题是否分开？
- [ ] 是否对齐上一期同类型训练营格式？
- [ ] 每天是否包含开场、回顾/说明、当天主题、总结、答疑、咨询承接和预告/结营？
- [ ] 是否按群消息意群组织，并使用统一分隔符？
- [ ] 是否擅自增加互动题或作业？

## 语言

- [ ] 是否存在错别字、重复词、病句和主谓不清？
- [ ] 口语表达是否自然而非营销化？
- [ ] 术语在全文是否统一？
- [ ] 当日总结和次日预告是否对应正文？

## 数据与事实

- [ ] 每个数字是否有对象、时间、指标和口径？
- [ ] 是否存在空缺数据句或占位符？
- [ ] 正文、图片、图注是否一致？
- [ ] 时点数据是否标明截止日期？
- [ ] 是否把一次历史区间结果写成普遍结论？

## 图片

- [ ] 每张图是否有对应正文和前后承接？
- [ ] 图片数据是否需要更新？
- [ ] 是否含具体产品名称、代码、机构、水印或无关二维码？
- [ ] 图片在手机端是否清晰？

## 合规

- [ ] 历史表现是否就近提示不代表未来？
- [ ] 是否存在“一定跑赢”“收益更好”等绝对表达？
- [ ] 股息是否被误写为固定收益？
- [ ] 私募增强是否被写成必然获得超额收益？
- [ ] 演示利率是否被误写为承诺收益？
- [ ] 是否提示早期退保风险？
- [ ] 港险是否限定为已有香港或海外资金的人群？
- [ ] 产品案例是否完成匿名化？

## 飞书

- [ ] 写入前是否读取最新版本？
- [ ] 是否保护用户内容、评论和图片？
- [ ] 是否只修改用户授权的范围？
- [ ] 写后是否重新读取验证？
